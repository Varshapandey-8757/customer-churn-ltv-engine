# Customer Churn & LTV Dashboard

## Dashboard Tool

Apache Superset

## Purpose

This dashboard provides business insights into customer churn,
customer segmentation, customer lifetime value (LTV), and
retention opportunities.

## Dashboard Sections

1. Executive Overview
2. Churn Risk Analysis
3. Customer Segmentation
4. LTV Analysis
5. High-Value Customers
6. Retention Insights

## Data Source

PostgreSQL database containing the processed customer churn
and feature-engineered data from the project pipeline.

## Key Metrics

- Total Customers
- Churned Customers
- Churn Rate
- Average Monthly Charges
- Average LTV
- High-Value Customers
- High-Risk Customers
