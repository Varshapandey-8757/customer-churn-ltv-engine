# Data

```
data/raw/        telco_customer_churn.csv   (original dataset, 7,043 rows, 21 columns)
data/processed/  generated by `make export-features` (not committed to git)
```

Processed files: `X_train.csv`, `X_test.csv`, `y_churn_*.csv`, `y_ltv_*.csv`,
`fct_churn_ltv_features.csv`, `feature_metadata.json`, `feature_pipeline.joblib`.

Split: stratified 80/20 on churn, `random_state=42`. Encoders and scalers are
fitted on the training part only.
